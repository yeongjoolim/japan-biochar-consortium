# Japan Biochar Consortium 사이트 (일본어 / 영어)

## 파일 구성
- index.html : 사이트 본체 (홈 / 研究会 / シンポジウム / 記事, 우측 상단에서 日本語·EN 전환)
- admin.html : 콘텐츠 관리 화면 (기사·심포지엄·연구회·사이트 정보 편집)
- content.js : 모든 콘텐츠 데이터 (이 파일만 바꾸면 내용이 바뀝니다)
- assets/    : 디자인(style.css)과 동작(app.js). 이미지는 assets/img/ 에 넣어 사용

## 비밀번호 (회원 전용)
- 콘텐츠는 content.enc.js에 암호화(AES-256)되어 있고, 첫 화면에서 비밀번호를 넣어야 풀립니다.
- 비밀번호는 admin.html의 [암호화해서 내보내기]에서 정합니다. 바꾸고 싶으면 새 비밀번호로 다시 내보내 올리면 됩니다.
- 비밀번호를 잊으면 복구할 수 없으니 따로 보관하세요. 로그아웃: 사이트 하단의 ログアウト.

## 내용 업데이트 방법
1. admin.html을 엽니다 (사이트 주소/admin.html). 처음엔 비밀번호를 물어봅니다.
2. 기사·심포지엄 등을 추가/수정 → [저장]. [미리보기]로 확인.
3. [암호화해서 내보내기] → 비밀번호 입력 → content.enc.js 다운로드.
4. GitHub 저장소에서 Add file → Upload files로 content.enc.js를 올려 덮어씁니다.

## 주의
- 기사 본문은 비어 있습니다. 원고를 admin.html에서 넣어 주세요.
- 연구회 설명 문구는 이름을 바탕으로 쓴 임시 문안이니 확인 후 수정하세요.
- 저장소에 암호화 안 된 content.js가 남아 있으면 내용이 노출됩니다. 처음 content.enc.js를 올린 뒤 content.js는 삭제하세요.
